# Algoritmos e Programação: Fundamentos 💻

Este repositório contém os exercícios, exemplos, conteúdos teóricos, trabalhos e provas que desenvolvi durante a disciplina de Algoritmos e Programação: Fundamentos, no curso de Ciência da Computação na Unisinos.

O objetivo deste espaço é acompanhar minha evolução na lógica de programação e registrar o aprendizado prático de conceitos essenciais da linguagem C, como:
* Variáveis, Tipos de Dados e Operadores
* Estruturas de Condição (if/else, switch)
* Estruturas de Repetição (while, for, do-while)
* Funções, Vetores e Matrizes
* Ponteiros
